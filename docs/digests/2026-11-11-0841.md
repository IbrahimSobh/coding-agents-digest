### Antigravity CLI
- ⚠️ **Enterprise gateway URLs must use https** (1.5.5). A remote gateway set to a plain `http://` URL is now rejected with an error, so change it to `https://`; localhost is still allowed. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.5)
- **Swarms in preview** (1.5.5). `/swarm <task>` makes the agent a coordinator that adds worker agents, which work in parallel on a shared message board and each use your quota. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.5)
- **Headless runs finish** (1.5.5). A stuck background task, such as title generation, no longer keeps `agy -p` running; the CLI now shuts down within 30 seconds. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.5)
