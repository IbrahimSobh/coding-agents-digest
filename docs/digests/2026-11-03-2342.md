### Claude Code
- **Asks before sending your email** (2.1.317). Web and shell tool calls now get a check that asks you first when they would send your account email address over the network. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.317)
- **Hook callbacks can block an action** (2.1.317). Agent SDK hook callbacks accept `onFailure: "block"`, so a callback that fails stops the action instead of letting it run. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.317)
- **Subagents use their own model's effort** (2.1.317). Subagents and teammates on a different model from the main conversation now use that model's saved effort level or its default, not the session's effort level. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.317)
