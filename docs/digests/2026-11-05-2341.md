### Antigravity CLI
- **ACP editors get every model on your account** (1.5.1). `agy acp` now offers all models your account can use to any editor client, not only Gemini models plus a fixed list. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.1)
- **Plugin tokens stay in the Authorization header** (1.5.1). In the terminal sandbox, a command can no longer make a website echo a plugin's real OAuth token back through another header or a URL. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.1)
- **Agent moves on faster after background processes** (1.5.1). After a terminal command exits, the agent now waits at most about 1 second instead of 5 if a background process still holds the output open. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.1)
