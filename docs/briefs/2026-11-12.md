# Claude Code 2.1.319 security fixes and exit-code changes lead; Fable 5.2 became the default and Codex 0.167.2 changed Vertex tool updates.

## 1. Permission and sandbox holes closed
Claude Code 2.1.319 closes a Bash permission bypass where a crafted environment prefix could hide part of a command, and a sandbox escape when creating a worktree ([2.1.319](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)). Antigravity CLI 1.5.3 fixes a terminal sandbox issue where a sandboxed command could change environment state that later persistent terminal commands loaded ([1.5.3](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.3)).

**So what:** update Claude Code to 2.1.319 and Antigravity CLI to 1.5.3 or later.

## 2. Scripts get clearer failure signals, and new denials
Claude Code 2.1.319 makes `claude -p` exit 1 when auto mode refuses actions, where it used to exit 0 ([2.1.319](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)). Antigravity CLI 1.5.2 denies some requests in headless `-p` runs that use `--dangerously-skip-permissions` ([1.5.2](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.2)), and 1.5.5 stops a stuck background task from keeping `agy -p` running ([1.5.5](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.5)).

**So what:** scripts that trust exit 0 or the raw output should check these signals now, and skip-permission jobs may be denied more often.

## 3. New defaults change cost and behavior
Claude Code 2.1.321 makes `claude-fable-5-2` the new default Fable model, with 1M context at $8/$40 per Mtok ([2.1.321](https://github.com/anthropics/claude-code/releases/tag/v2.1.321)). Codex 0.167.2 sends tool updates incrementally by default on Google Cloud Vertex AI ([rust-v0.167.2](https://github.com/openai/codex/releases/tag/rust-v0.167.2)), and Antigravity CLI 1.5.2 makes macOS Option-key shortcuts work by default ([1.5.2](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.2)).

**So what:** check the price of the Fable default before you rely on it, and re-check any pinned terminal or Vertex setting.
