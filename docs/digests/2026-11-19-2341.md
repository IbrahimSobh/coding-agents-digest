Claude Code, Antigravity CLI · 2 releases, 98 bug fixes

### Claude Code
- ⚠️ **MCP headers no longer follow a redirect** (2.1.328). Custom headers such as API keys on an HTTP MCP server could be sent to a different host after a redirect; update to 2.1.328 so they go only to the configured server. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.328)
- ⚠️ **Sandbox network rules could be bypassed** (2.1.328). A command could get around path-based rules for credentials and Git or API paths using `%2F`, backslashes or `..`; update to 2.1.328. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.328)
- ⚠️ **Code Mode output skips UserPromptSubmit hooks** (2.1.328). If a UserPromptSubmit hook redacts or changes script output, move that step to a PostToolUse hook that returns `updatedToolOutput`. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.328)
- **Auto mode on more platforms** (2.1.328). Opus 4.6 and Sonnet 4.6 get auto mode on Bedrock, Google Cloud's Agent Platform, Foundry and the Claude apps gateway, and interactive sessions with no permission mode now start in it. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.328)
- **`/code-review` reports less** (2.1.328). On most models it now reports only bugs and CLAUDE.md violations, so run `/simplify` for reuse and efficiency cleanups. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.328)

### Antigravity CLI
- **Gemini 4 Neon in `/model`** (1.5.12). Low, Medium, High and XHigh levels are added to `/model` and `--model` when you connect with a `GEMINI_API_KEY`. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.12)
- **Split view in Remote Control** (1.5.12). The browser view can keep several conversations side by side; pick `Split Right` or `Split Down` from a conversation's menu. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.12)
- **Markdown headings without `#` markers** (1.5.12). Headings in agent responses and artifacts now show as bold, italic or underlined text instead of raw `##` markers. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.12)
