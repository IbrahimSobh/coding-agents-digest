### Antigravity CLI
- **Optional API keys for plugins** (1.4.12). A plugin's `auth.json` can set `"optional": true` for an API key provider, so an unset key makes its commands send unauthenticated requests at the free rate limit instead of failing with 401 or asking you to sign in. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.12)
