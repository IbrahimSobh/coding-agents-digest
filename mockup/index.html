The week in one line

The agents got more autonomous and more careful, and their plugins started to converge.

Busiest: Claude Code (8 releases). Quietest: Codex CLI (1 stable, ~10 alphas). Rebuilt on every run.

1 · AUTONOMYAutonomy, with a guard in front

agy extended Auto mode, where a review agent checks risky commands, to subagents (1.4.3) and Windows (1.4.4); Claude Code added /auto-mode-setup (2.1.304).

So what: “approve every command” is ending; the safety check is the new battleground.

2 · PLUGINSPlugins are becoming portable

agy accepts plugins “written for other tools” (1.4.5) and flags Claude Code-style hook keys (1.4.3).

So what: one plugin may soon run in several agents.

3 · COSTLong sessions got cheaper

Claude Code made idle compaction a /config switch (2.1.302); agy halved idle CPU (1.4.5).

So what: an agent session open all day is becoming normal.
