Claude Code, Antigravity CLI · 2 releases, 248 bug fixes

### Claude Code
- ⚠️ **Hook `"decision": "block"` holds in more cases** (2.1.326). A hook that always prints it may now stop tool calls it used to let through, so remove that output where a call should pass. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.326)
- ⚠️ **Sandboxed commands no longer write to some home folders** (2.1.326). Writes to those folders may now be blocked, so add any folder a job needs to `sandbox.filesystem.allowWrite` in user or managed settings. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.326)
- **Startup warning for incomplete rules** (2.1.326). Claude Code now warns when an `--allowedTools`, `--disallowedTools` or `--tools` value does not look like a complete rule, so a typo in a script shows up at startup. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.326)
- **Replies stream to phones and browsers** (2.1.326). Remote Control replies from `claude remote-control`, Claude Desktop and VS Code sessions now appear as they are written. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.326)

### Antigravity CLI
- ⚠️ **Remote agent asks before each edit** (1.5.10). Sessions start in default mode, where the agent asks before every file edit, so unattended `--remote-agent` runs may wait for approval until you switch to `accept-edits` with `Shift+Tab`. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.10)
- ⚠️ **Sandbox blocks reads of `~/.config`** (1.5.10). Sandboxed commands can no longer read `~/.config` or `XDG_CONFIG_HOME` by default, and `~/.git-credentials` is now blocked too, so allow any path a command needs in your sandbox rules. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.10)
- **Orchestrator model in `/model`** (1.5.10). Gemini Enterprise accounts and Application Default Credentials sign-ins get a row that plans with Gemini 4 Carbon (High) and runs the plan on Gemini 4 Hydrogen (High). [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.10)
- **Longer rate-limit waits** (1.5.10). The CLI now waits and retries for delays up to 4 minutes, so per-minute limits no longer end the turn, while spend-cap and quota errors still stop it at once. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.10)
