### Antigravity CLI
- **Auto mode asks less often on safe reads** (1.5.6). GitHub API reads, fetches into an existing clone and single-file downloads now pass without the repository checks; private keys and `.ssh` exfiltration stay blocked. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.6)
- **Stop hooks get `continuation_active`** (1.5.6). The Stop hook JSON input now has this field, which is `true` when the agent is already continuing from an earlier Stop hook, so a hook can avoid looping. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.6)
- **Auto mode for more pay-as-you-go accounts** (1.5.6). Accounts that sign in with Application Default Credentials (`AGY_ADC_AUTH`) now get Auto mode like other pay-as-you-go accounts, while Gemini Enterprise accounts still do not. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.6)
