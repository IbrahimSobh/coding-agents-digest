### Claude Code
- **Easel chart mod** (2.1.330). A built-in mod that draws charts when you ask and under MCP metrics results, on Pro, Max and, where available, Team and Enterprise on macOS and Linux; turn automatic charts off in `/config`. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.330)
- **Bug fixes** (2.1.330). 77 fixes, including freezes after compacting a long conversation and `/rewind` sometimes restoring an older version of a file. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.330)

### Antigravity CLI
- ⚠️ **Windows credential leak through UNC paths fixed** (1.5.14). Network (UNC) and device paths in workspace permission rules, `@` mentions, plugins and custom agents could send Windows credentials to a remote host, so update to 1.5.14 or later. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.14)
- **Auto mode reads outside the workspace** (1.5.14). Auto mode no longer asks before reading files outside the workspace; writing or editing there still asks, and your `ask` and `deny` rules still apply. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.14)
- **`/thinking` toggle** (1.5.14). `/thinking [on|off]` streams the model's full thinking live in the transcript; it is off by default and saved as `showThinking` in `settings.json`. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.14)
- **Bug fixes** (1.5.14). 16 fixes, including `Esc` now canceling a message before it is sent and wide Markdown tables keeping their column headers. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.14)
