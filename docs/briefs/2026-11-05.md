# Antigravity CLI 1.5.0 adds an ACP editor server and changes headless exit codes; Opus 4.8 fast mode ends Nov 30.

## 1. Scripts get clearer failure signals
Claude Code 2.1.314 makes `claude -p` print the error and exit 1 when startup fails ([2.1.314](https://github.com/anthropics/claude-code/releases/tag/v2.1.314)). Antigravity CLI 1.5.0 exits with code `3` when `--print-timeout` cuts a run short ([1.5.0](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.0)).

**So what:** scripts that trust exit code 0 or the raw output should check these signals now.

## 2. Opus 4.8 fast mode ends Nov 30
Claude Code 2.1.316 deprecates fast mode for Opus 4.8 and removes it on November 30, 2026 ([2.1.316](https://github.com/anthropics/claude-code/releases/tag/v2.1.316)). After that, fast-mode requests on Opus 4.8 return an error.

**So what:** move fast mode to Opus 5.5 before the removal date, or those requests will fail.

## 3. Subagent and thread defaults moved
Claude Code 2.1.317 makes subagents on a different model use that model's effort level, not the session's ([2.1.317](https://github.com/anthropics/claude-code/releases/tag/v2.1.317)). Codex cuts the default thread unload delay to one minute ([rust-v0.166.0](https://github.com/openai/codex/releases/tag/rust-v0.166.0)).

**So what:** a subagent or Codex thread may now run with different effort or timing than last week, so re-check any pinned setting.

## Action needed at the time
- **Fast mode on Opus 4.8 is being removed** (Claude Code [2.1.316](https://github.com/anthropics/claude-code/releases/tag/v2.1.316)): move fast mode to Opus 5.5 before November 30, 2026, since its requests will then return an error and not fall back.
- **Detached delivery removed from review/start** (Codex [rust-v0.166.0](https://github.com/openai/codex/releases/tag/rust-v0.166.0)): change those calls before you upgrade, since the release notes name no replacement (verify).
- **IDE extension no longer installed from IDE terminals** (Claude Code [2.1.318](https://github.com/anthropics/claude-code/releases/tag/v2.1.318)): install or update the extension from your editor's extensions view, or run `/ide` from an outside terminal.
- **Headless runs wait for background tasks** (Antigravity CLI [1.5.0](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.0)): set `--print-timeout` to a limit you accept, and treat exit code `3` as a run that was cut short.

**👀 Watch next:** Test `agy -p` jobs against 1.5.0 before you upgrade, since a timed-out run now exits 3, and move Opus 4.8 fast mode off before November 30.
