### Claude Code
- **Claude Fable 5.2 is the new default Fable model** (2.1.321). `claude-fable-5-2` has 1M context and costs $8/$40 per Mtok, with $0.20/Mtok for cache reads, so check the price before you rely on it. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.321)
- **MCP OAuth stops sending secrets to other hosts** (2.1.321). Refresh tokens and other secrets were sent to a different host when an MCP server redirected the OAuth request, and that is now fixed. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.321)
- **`--settings` for remote control** (2.1.321). `claude remote-control --settings <file>` applies a settings file to every session it starts, and after a file change no new session starts until you restart `claude remote-control`. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.321)
