### Kilo Code
- **Auto-approve is now a user-level setting** (v7.8.40). In VS Code, auto-approve is no longer a per-project choice, and the notes do not say how existing settings carry over, so check your rules after updating. [Source](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.40)
- **Shell commands that print env files ask first** (v7.8.40). Commands that print `.env`-style files now ask for permission in VS Code and the CLI, so expect a few more prompts. [Source](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.40)
- **Provider credentials go only to their own hosts** (v7.8.40). Keys and bearer tokens are sent only to the matching host, such as Cloudflare AI Gateway and Vertex. [Source](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.40)
