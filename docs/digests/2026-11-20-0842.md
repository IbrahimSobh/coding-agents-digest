### Claude Code
- ⚠️ **Saved scheduled tasks need scheduling again** (2.1.329). In new signed-in sessions, most tasks saved by earlier versions need to be scheduled again; resuming their own session with `--resume` still runs them. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.329)
- ⚠️ **Code Mode hooks no longer block on error** (2.1.329). A PreToolUse hook that errors no longer refuses a script's tool call, so add `"onFailure": "block"` to each command, HTTP or MCP tool hook that must refuse. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.329)
- **`/tasks` lists scheduled tasks and loops** (2.1.329). It now shows this session's scheduled tasks, `/loop` wakeups and forks, and `x` stops one after asking. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.329)
- **Code Mode works with telemetry on** (2.1.329). It can run while OpenTelemetry events and metrics are enabled, and each tool call the code makes sends its events. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.329)
- **`/code-review <pr number>` reads the real pull request** (2.1.329). It now uses `gh pr diff` instead of sometimes reviewing the checked-out branch, and says so when it cannot. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.329)

### Antigravity CLI
- **Gemini 4 Neon with ADC sign-in** (1.5.13). Low, Medium, High and XHigh now appear in `/model` and `--model` when you sign in with Application Default Credentials (`AGY_ADC_AUTH`). [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.13)
- **Fewer turns on multi-step tasks** (1.5.13). The agent runs independent searches, file reads and edits in one step, and chains related shell commands, so tasks take fewer turns. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.13)
- **Swarm only when you type `/swarm`** (1.5.13). Agents no longer start a swarm on their own, which could use far more of your quota. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.13)
