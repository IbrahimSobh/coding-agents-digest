### Claude Code
- ⚠️ **Security fix in zstd response decoding** (2.1.325). Update Claude Code to 2.1.325 or later. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.325)
- ⚠️ **Sandboxed Bash asks for permission by default** (2.1.325). Set `sandbox.autoAllowBashIfSandboxed: true` to keep running sandboxed commands without prompts, or unattended jobs may wait for approval. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.325)
- ⚠️ **Scheduled tasks and `/loop` ask before some skills** (2.1.325). A skill that declares `allowed-tools` or hooks now asks first, so add `Skill(name)` to `permissions.allow` to run it unattended. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.325)
- **Bash allow rules run the program they name** (2.1.325). A case where a Bash allow rule could run a different program is fixed, and some compound commands that could run without asking now ask first. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.325)
- **Subagents cut off at the output limit retry** (2.1.325). They are asked for the whole answer again, more briefly, instead of returning only the end of it. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.325)
