# Coding agents update

**Oct 14 to Oct 21, 2026** · Claude Code, Antigravity CLI, Codex CLI, Cline, Kilo Code · 22 releases, 456 bug fixes

## In one minute

- ⚠️ **Claude Code: MCP allow rules now match only the exact server** (2.1.299). A rule `mcp__a` no longer allows a server named `a__b`, so write `mcp__<server>__*` with the full server name or some tools will start asking for approval. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.299)
- ⚠️ **Claude Code: standalone Claude Design closes on December 14, 2026** (2.1.302). `/design-sync` and `/design-login` now show this notice, so plan to move any work you keep there. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.302)
- ⚠️ **Cline: OpenAI Compatible base URLs are used exactly as typed** (v4.1.25). A new host-only URL like `https://abc.com` no longer gets `/v1` added, so type it yourself if your server needs it. [Source](https://github.com/cline/cline/releases/tag/v4.1.25)
- **Claude Code: idle compaction** (2.1.299). A conversation over 200K tokens that sits idle for about 54 minutes is compacted before its prompt cache expires, so coming back after a break costs much less; turn it off with `"idleCompaction": false`. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.299)
- **Claude Code: `/auto-mode-setup`** (2.1.304). It reads your project and recent sessions to teach auto mode about your environment, which helps when auto mode blocks normal commands. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.304)
- **Antigravity CLI: Auto mode** (1.3.5). It approves edits and safe commands without asking, and a separate agent reviews commands that would leave the sandbox; pick it with `--mode auto` or `Shift+Tab`. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.3.5)
- **Antigravity CLI: `agy plugin validate --strict --json`** (1.4.0). It now uses the same rules the CLI uses to load plugins, so you can run it in CI and fail on warnings. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.0)
- **Codex CLI: steer Codex mid-answer, plus a searchable `/config`** (0.163.0). A follow-up sent while Codex is responding changes its direction right away, without waiting for the turn to end. [Source](https://github.com/openai/codex/releases/tag/rust-v0.163.0)
- **Cline: Cloud sessions** (v4.1.25). Run a task in a hosted sandbox on a GitHub repo and branch you choose; it is rolling out gradually and is turned on in Settings. [Source](https://github.com/cline/cline/releases/tag/v4.1.25)
- **Kilo Code: new Agent Manager worktree dialog** (v7.8.15). It adds a base-branch picker, so parallel agents in git worktrees start from the right branch. [Source](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.15)
- **Shared theme: more autonomy, with a reviewer in front.** agy got Auto mode with a review agent, and Claude Code got a guided setup for its auto mode; Claude Code, agy and Cline also all added automatic retries for broken streams or tool calls. Sources: [agy](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.3.5), [Claude Code](https://github.com/anthropics/claude-code/releases/tag/v2.1.304), [Cline](https://github.com/cline/cline/releases/tag/cli-v3.0.72)
