Claude Code, Antigravity CLI, Codex CLI · 3 releases, 88 bug fixes

### Claude Code
- **Block writes outside working directories** (2.1.314). Turn on the new `permissions.blockWritesOutsideWorkingDirectories` setting to make Write, Edit and NotebookEdit refuse paths outside your working directories in every permission mode. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.314)
- **Idle compaction in VS Code and Desktop** (2.1.314). In VS Code and Claude Desktop's Code tab, an idle conversation over 200K tokens gets summarized, and that summary is used on your next message if the prompt cache has expired. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.314)
- **`claude -p` now exits 1 when startup fails** (2.1.314). It prints the error instead of exiting 0 with no output, so scripts that check the exit code now see the failure. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.314)

### Antigravity CLI
- **Billing choice after Google Cloud sign-in** (1.4.11). You pick a Gemini subscription or Pay As You Go once you sign in with Google Cloud. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.11)
- **`terminationBehavior` on PreInvocation hooks** (1.4.11). Returning `"terminate"` stops the turn before the model is called, for example to block a prompt that contains sensitive data. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.11)
- **`finished_reason` in JSON output** (1.4.11). The `--output-format json` and `stream-json` results say why a turn ended early (`print_timeout`, `interrupted` or `error`), so scripts can tell a cut-off answer from a full one. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.11)

### Codex CLI
- ⚠️ **Detached delivery removed from `review/start`** (rust-v0.166.0). If your API client sends `review/start` with detached delivery, change that call before you upgrade, since the notes name no replacement (verify). [Source](https://github.com/openai/codex/releases/tag/rust-v0.166.0)
- **GPT-6.1 Terra added** (rust-v0.166.0). It is in the bundled, Vertex AI and Amazon Bedrock model catalogs. [Source](https://github.com/openai/codex/releases/tag/rust-v0.166.0)
- **Thread unload delay now one minute** (rust-v0.166.0). The default delay before an idle thread unloads is cut to one minute. [Source](https://github.com/openai/codex/releases/tag/rust-v0.166.0)
