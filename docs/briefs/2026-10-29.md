# Claude Code and Codex changed defaults this week, and Antigravity CLI 1.4.9 now needs separate approval for Google apps.

## 1. Defaults shift under you again
Codex turns memory v2 on for new profiles ([rust-v0.165.0](https://github.com/openai/codex/releases/tag/rust-v0.165.0)) and runs its Guardian classifier in conversation mode by default ([rust-v0.164.0](https://github.com/openai/codex/releases/tag/rust-v0.164.0)). Claude Code widens automatic model switches to custom model names ([2.1.312](https://github.com/anthropics/claude-code/releases/tag/v2.1.312)).

**So what:** a setting that gave you one result last week may give another now, so check the new defaults before you rely on them.

## 2. Security fixes and tighter sandboxes
OpenCode's bundled Bun gets security fixes ([v1.19.4](https://github.com/anomalyco/opencode/releases/tag/v1.19.4)), and Claude Code's sandboxed commands can no longer change the `--mcp-config` file ([2.1.309](https://github.com/anthropics/claude-code/releases/tag/v2.1.309)).

**So what:** update the tools that carry security fixes, and give sandboxed commands the explicit access they still need.

## 3. Subagents keep their task after compaction
Antigravity CLI 1.4.10 stops subagents from losing the task and parent ID their parent agent gave them after compaction, including with `/compact` ([1.4.10](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.10)).

**So what:** long sessions with subagents are less likely to lose their task, so restarting them is needed less often.
