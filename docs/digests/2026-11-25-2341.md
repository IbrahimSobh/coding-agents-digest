### Antigravity CLI
- ⚠️ **Sensitive files bypassed approval in enterprise sessions** (1.5.17). Gemini Enterprise and enterprise model-gateway sessions with non-workspace file access could skip approval and deny rules on `.git`, `.env` and other sensitive files, so update to 1.5.17 or later. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.17)
- **Mouse text selection in the prompt box** (1.5.17). In full screen mode you can click to move the cursor and drag or double-click to select text, with `Ctrl+C` to copy and `Ctrl+X` to cut. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.17)
- **Long commands wake the agent** (1.5.17). `run_command` can set `NotificationTimeoutSeconds`, so the agent is notified when a background command is still running instead of polling it in extra turns. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.17)
