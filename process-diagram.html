How Coding Agents Digest works

Twice a day, a Claude scheduled task checks 5 coding agents, writes a short digest, and GitHub publishes it as a website and an RSS feed.

Memory in a file

Each run starts fresh. state.json keeps the last tag per tool, so a run covers only releases it has not seen.

Prompt as code

The rules live in task/PROMPT.md. Edit and push, and the next run follows them.

No servers

Claude runs the task, GitHub stores and hosts. A few cents per run.
