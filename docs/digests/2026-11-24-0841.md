### Antigravity CLI
- **Live step checklist under the prompt** (1.5.16). While the agent tracks its steps, the status line shows `N/M steps` and an open checklist of up to seven steps. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.16)
- **`-r` alias for resume** (1.5.16). `agy -r <id>` and `agy --resume <id>` resume a saved conversation by ID, the same as `--conversation`. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.16)
- **Auto mode asks less outside the workspace** (1.5.16). It no longer asks before creating or editing files inside a Git, Jujutsu or Mercurial repository, or when a change only adds content; replacing existing lines outside a repository still asks. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.16)

### Codex CLI
- **Thread links open saved conversations** (rust-v0.172.0). Thread links in search results and transcripts open the saved conversation or nested agent in the terminal. [Source](https://github.com/openai/codex/releases/tag/rust-v0.172.0)
- **Stdio MCP servers start on first use** (rust-v0.172.0). Optional stdio MCP servers with a cached tool list now start on their first tool call instead of at launch. [Source](https://github.com/openai/codex/releases/tag/rust-v0.172.0)
- **`code_mode_host_grpc` is deprecated** (rust-v0.172.0). Code Mode now uses gRPC for all host connections, and the `code_mode_host_grpc` setting is deprecated. [Source](https://github.com/openai/codex/releases/tag/rust-v0.172.0)
