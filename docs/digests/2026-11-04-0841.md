Claude Code, Antigravity CLI · 2 releases, 50 bug fixes

### Claude Code
- ⚠️ **IDE extension no longer installed from IDE terminals** (2.1.318). Claude Code no longer installs or updates the IDE extension when started in an IDE terminal, so install it from your editor's extensions view or run `/ide` from an outside terminal. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.318)
- **Sign-in expiry shows in scripts** (2.1.318). `claude auth status` and `claude -p` JSON now report when a claude.ai sign-in ends, and `claude -p` warns on stderr 10 days before. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.318)
- **Cloud sessions can start with no repository** (2.1.318). Anthropic-hosted environments now have a No repository option, so a session can start without picking one. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.318)

### Antigravity CLI
- ⚠️ **Headless runs wait for background tasks** (1.5.0). Without `--print-timeout`, `agy -p` now waits for background tasks instead of stopping them after a hidden 30-minute limit, and a timed-out run exits 3. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.0)
- **ACP server for editors** (1.5.0). `agy acp` runs the CLI as an Agent Client Protocol server over stdio, so an editor can use it as its agent. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.0)
- **Remote agents** (1.5.0). `--remote-agent` runs conversations on remote agents, with `--project` choosing a remote project by ID or name. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.0)
