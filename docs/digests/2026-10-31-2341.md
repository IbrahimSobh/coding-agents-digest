### Claude Code
- ⚠️ **Fast mode on Opus 4.8 is being removed** (2.1.316). Fast mode for Opus 4.8 is deprecated and will be removed on November 30, 2026; after that its requests return an error instead of falling back, so move them to Opus 5.5 before then. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.316)
- **Subagent effort setting** (2.1.316). `CLAUDE_CODE_SUBAGENT_EFFORT` sets the effort level subagents run at when nothing else names one, instead of inheriting the session's. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.316)
- **Turn off the ultrathink keyword** (2.1.316). `CLAUDE_CODE_DISABLE_ULTRATHINK` turns the `ultrathink` keyword off. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.316)
