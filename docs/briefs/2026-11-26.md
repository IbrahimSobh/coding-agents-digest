# Security fixes led the week, and new defaults in Codex, Kilo Code and Claude Code changed what runs out of the box.

## 1. Permission and sandbox holes closed
Claude Code 2.1.328 closes an MCP header leak on redirect and a sandbox network-rule bypass ([v2.1.328](https://github.com/anthropics/claude-code/releases/tag/v2.1.328)). Antigravity CLI 1.5.14 fixed a Windows credential leak through UNC paths, and 1.5.17 closes a bypass of approval and deny rules on sensitive files in Gemini Enterprise sessions ([1.5.14](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.14), [1.5.17](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.17)). Kilo Code v7.8.32 carries the hono and node-forge security updates ([v7.8.32](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.32)).

**So what:** update Claude Code to 2.1.328 or later, Antigravity CLI to 1.5.17 or later and Kilo Code to 7.8.32 or later.

## 2. New defaults change models, effort and updates
Codex CLI [rust-v0.171.0](https://github.com/openai/codex/releases/tag/rust-v0.171.0) made GPT-6.2 Sol the default model, and Antigravity CLI [1.5.15](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.15) defaults Orchestrator effort to high when unset. Claude Code [2.1.331](https://github.com/anthropics/claude-code/releases/tag/v2.1.331) auto-updates managed plugin marketplaces from November 30 unless you set `autoUpdate` to false.

**So what:** pin the model, effort and marketplace settings you rely on before the defaults apply to your jobs.

## 3. Auto mode runs more steps without asking
Claude Code [2.1.328](https://github.com/anthropics/claude-code/releases/tag/v2.1.328) added auto mode for Opus 4.6 and Sonnet 4.6 on more cloud providers, and [2.1.332](https://github.com/anthropics/claude-code/releases/tag/v2.1.332) starts sessions in auto mode on some clouds. Antigravity CLI [1.5.14](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.14) stopped asking before reads outside the workspace, and [1.5.16](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.16) asks less often before edits inside Git, Jujutsu or Mercurial repositories.

**So what:** fewer prompts also means fewer checkpoints, so keep your ask and deny rules current.

## Action needed at the time
- **MCP headers no longer follow a redirect** (Claude Code [2.1.328](https://github.com/anthropics/claude-code/releases/tag/v2.1.328)): update Claude Code to 2.1.328.
- **Sandbox network rules could be bypassed** (Claude Code [2.1.328](https://github.com/anthropics/claude-code/releases/tag/v2.1.328)): update Claude Code to 2.1.328.
- **UserPromptSubmit hooks no longer see Code Mode output** (Claude Code [2.1.328](https://github.com/anthropics/claude-code/releases/tag/v2.1.328)): move that step to a PostToolUse hook that returns `updatedToolOutput`.
- **Saved scheduled tasks need scheduling again** (Claude Code [2.1.329](https://github.com/anthropics/claude-code/releases/tag/v2.1.329)): schedule each one again, or resume its own session with `--resume`, which still runs it.
- **Code Mode hooks no longer block on error** (Claude Code [2.1.329](https://github.com/anthropics/claude-code/releases/tag/v2.1.329)): add `"onFailure": "block"` to each command, HTTP or MCP tool hook that must refuse.
- **GPT-6.2 Sol is the new default model** (Codex CLI [rust-v0.171.0](https://github.com/openai/codex/releases/tag/rust-v0.171.0)): set the model you rely on in your config so the default change does not alter your results (setting name to verify).
- **Codestral is now the default autocomplete model** (Kilo Code [v7.8.30](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.30)): re-select your autocomplete model if you want another one than Codestral.
- **client.kilo.edit is removed from the SDK** (Kilo Code [v7.8.30](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.30)): remove those calls and imports before you update, since they no longer exist.
- **Security updates for hono and node-forge** (Kilo Code [v7.8.30](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.30)): update Kilo Code to v7.8.32 or later, which carries the hono and node-forge updates.
- **Windows credential leak through UNC paths fixed** (Antigravity CLI [1.5.14](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.14)): update Antigravity CLI to 1.5.14 or later.
- **Managed plugin marketplaces auto-update by default** (Claude Code [2.1.331](https://github.com/anthropics/claude-code/releases/tag/v2.1.331)): set `"autoUpdate": false` on each entry before November 30, 2026, to keep it fixed.
- **Orchestrator effort now defaults to high** (Antigravity CLI [1.5.15](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.15)): open `/model` and set Planner and Executor effort back to the highest level to keep the old depth.
- **Terminal and VS Code start in auto mode on some clouds** (Claude Code [2.1.332](https://github.com/anthropics/claude-code/releases/tag/v2.1.332)): set `disableAutoMode` to `"disable"` to stop sessions starting in auto mode.
- **Sensitive files bypassed approval in enterprise sessions** (Antigravity CLI [1.5.17](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.17)): update Antigravity CLI to 1.5.17 or later.

**👀 Watch next:** Claude Code's marketplace auto-update starts on November 30, so review managed marketplace settings before then. Also watch whether the new Codex default model changes results in your sessions.
