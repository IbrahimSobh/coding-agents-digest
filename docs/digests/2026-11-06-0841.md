### Antigravity CLI
- ⚠️ **Headless runs deny some requests under `--dangerously-skip-permissions`** (1.5.2). Protected commands are no longer approved automatically, and headless `-p` runs deny requests your admin requires to be reviewed; run those jobs once and look for denied commands before the next scheduled run. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.2)
- **Remote-agent skills** (1.5.2). Skills from cloud plugins you connected with `/plugin` now appear in the `/` menu for `--remote-agent` sessions, and `/skills` lists them. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.2)
- **Stricter plugin and repo loading** (1.5.2). Plugin names must be safe file names, and workspace plugins and skills load only from inside the repository, which guards against malicious plugins and untrusted repositories. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.2)
- **macOS Option-key shortcuts work by default** (1.5.2). Shortcuts such as `alt+m` now work without setting Option as Alt in your terminal; set `AGY_CLI_MAC_OPTION_AS_ALT=0` to keep the old behavior. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.2)

### Codex CLI
- **Agent command center** (rust-v0.167.0). `codex agents --no-daemon` opens a view of your agents that marks results you have not read yet; it is a new command. [Source](https://github.com/openai/codex/releases/tag/rust-v0.167.0)
- **Switch backends in the session picker** (rust-v0.167.0). The terminal session picker can switch between connected backends and keeps your draft. [Source](https://github.com/openai/codex/releases/tag/rust-v0.167.0)
