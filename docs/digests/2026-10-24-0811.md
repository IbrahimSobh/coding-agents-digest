Claude Code, Antigravity CLI · 2 releases, 21 bug fixes

### Claude Code
- **Lower memory use for `-p` and Agent SDK compaction** (2.1.310). Non-interactive sessions use less memory when they compact a very large transcript, which helps long scripted runs. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.310)
- **Clearer MCP timeout error in non-interactive runs** (2.1.310). If an MCP server's elicitation goes unanswered, Claude now gets a message saying no answer came and not to repeat the call. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.310)

### Antigravity CLI
- ⚠️ **Plugin MCP sign-ins may need a new login** (1.4.7). Their OAuth tokens now belong to the signed-in user, so sign in to each plugin MCP server that uses OAuth again after you update to 1.4.7. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.7)
- **Hooks get `lastUserInput`** (1.4.7). Hook commands receive your latest message on stdin, so a hook can screen prompts before the agent acts on them. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.7)
- **Auto mode asks less often** (1.4.7). Routine commands such as cleaning up temporary files, stopping a local process or running a formatter need less approval. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.7)
- **Lighter headless `-p` runs** (1.4.7). They use much less CPU, and they no longer start your custom status line or window title commands. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.7)
