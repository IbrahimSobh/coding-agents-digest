### Claude Code
- ⚠️ **`mcp add` stops on a top-level `.mcp.json`** (2.1.327). `claude mcp add --scope project` now stops instead of overwriting the file, so move the servers under an `mcpServers` key first. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.327)
- ⚠️ **Auto mode ignores broad allow rules** (2.1.327). Rules like `Bash(pnpm dlx *)` no longer skip the safety check, so run the job once and add an exact rule for each command it still asks about. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.327)
- ⚠️ **Shell startup files run before approval** (2.1.327). Startup files may now run before the first Bash command is approved, even if it is refused, so set `CLAUDE_CODE_DISABLE_SHELL_HEAD_START=1` to turn that off. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.327)
- **Remote MCP servers retry after long outages** (2.1.327). Most remote servers reached by hostname over https are now retried in the background for about a day after a drop such as a VPN outage. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.327)

### OpenCode
- **OpenCode 2.0 upgrade offer** (v1.19.6). The desktop app offers an upgrade to OpenCode 2.0 that installs only when you choose to restart, upgrade on quit, or postpone, and plugins written for OpenCode 1 need an update first. [Source](https://github.com/anomalyco/opencode/releases/tag/v1.19.6)
- **Long image sessions recover** (v1.19.6). When image history passes 25 MiB the oldest images become a placeholder, and a too-large request now triggers compaction and a retry instead of failing the turn. [Source](https://github.com/anomalyco/opencode/releases/tag/v1.19.6)
