### Claude Code
- ⚠️ **Terminal and VS Code start in auto mode on some clouds** (2.1.332). On Bedrock Mantle, Agent Platform and Foundry, sessions now start in auto mode; set `disableAutoMode` to `"disable"` to stop it. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.332)
- **Skills from MCP servers, in beta** (2.1.332). MCP servers can now supply skills, shown in the `/` menu as `server:skill`. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.332)
- **`PreSkillShellCommand` hook** (2.1.332). A new hook event can refuse a skill's or command's inline shell commands as it loads. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.332)
- **`/permissions` explains skipped rules** (2.1.332). It now refuses a rule that would be skipped at the next start, such as `rm -rf` with no tool name, and shows why. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.332)
