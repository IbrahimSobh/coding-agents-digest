### Claude Code
- **Fast mode on Vertex** (2.1.322). Added in the global, us and eu regions; if Vertex refuses it, Claude Code falls back to standard speed. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.322)

### Antigravity CLI
- **Auto mode in `agy acp` sessions** (1.5.4). Editors can switch a session to `auto`: edits inside the workspace are approved, commands run in the terminal sandbox, and commands that would leave the sandbox still ask unless Auto mode's review clears them. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.4)
- **Hooks get more input** (1.5.4). Hook JSON now includes `hookEventName`, `cwd` and `toolCall.id`, so one hook command can handle several events and match a `PostToolUse` call to its `PreToolUse` call. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.4)
