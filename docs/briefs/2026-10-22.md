# The agents got more autonomous and more careful, and their plugin systems got stricter.

## 1. Autonomy, with a guard in front
agy extended Auto mode, where a review agent checks risky commands, to subagents ([1.4.3](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.3)) and Windows ([1.4.4](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.4)); Claude Code added `/auto-mode-setup` ([2.1.304](https://github.com/anthropics/claude-code/releases/tag/v2.1.304)).

**So what:** "approve every command" is ending; how good the safety check is becomes the real difference.

## 2. Plugins are checked before they load
`agy plugin validate` now uses the loader's own rules, with `--strict` and `--json` for CI ([1.4.0](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.0)), and it warns about Claude Code-style hook keys ([1.4.3](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.3)).

**So what:** if you write plugins for more than one agent, test them in each one's validator.

## 3. Long sessions got cheaper
Claude Code made idle compaction a `/config` switch ([2.1.302](https://github.com/anthropics/claude-code/releases/tag/v2.1.302)); agy cut CPU and memory use while streaming ([1.4.4](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.4)).

**So what:** leaving an agent session open all day is becoming normal.
