### Kilo Code
- ⚠️ **Codestral is now the default autocomplete model** (v7.8.30). Mercury Edit 2 and Next Edit are retired, and saved Mercury or Inception choices now use Codestral, so re-select your autocomplete model if you want another one. [Source](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.30)
- ⚠️ **`client.kilo.edit` is removed from the SDK** (v7.8.30). The SDK no longer has `client.kilo.edit`, and `@kilocode/kilo-gateway` no longer exports `./edit` or `./edit-prompt`, so remove those calls and imports before you update. [Source](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.30)
- ⚠️ **Security updates for hono and node-forge** (v7.8.30). The CLI moves to hono 4.13.18 and node-forge 1.4.3 to fix issues flagged by Dependabot, so update Kilo Code to v7.8.32 or later. [Source](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.30)
- **Held keys no longer confirm worktree deletion** (v7.8.32). In the VS Code Agent Manager, deleting a worktree now needs the Delete button or a separate Backspace or Delete press. [Source](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.32)
- **Telemetry preference can be changed in VS Code** (v7.8.31). Set it in VS Code's About tab or through the core telemetry API; it stays off if Kilo config, VS Code or the environment disables it. [Source](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.31)
