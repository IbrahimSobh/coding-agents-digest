### Antigravity CLI
- **Lighter streaming** (1.4.10). Agent replies write about 70% fewer bytes to the terminal, which keeps output smooth over slow SSH connections. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.10)
- **Large images no longer rejected** (1.4.10). Images are capped at 2000 pixels per side and large PNGs are sent as JPEGs, so conversations with many screenshots stop failing on the request size limit. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.10)
- **Less memory after startup** (1.4.10). About 100 MB left over from startup goes back to the operating system 15 seconds after the interactive UI opens; print and headless modes are unaffected. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.10)

### Kilo Code
- ⚠️ **Zod memory-exhaustion fix** (v7.8.20). The VS Code extension now uses a patched zod that fixes a memory-exhaustion advisory; update to v7.8.20 or later. [Source](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.20)
- **Base branch choice** (v7.8.20). Agents can choose the base branch when they start an Agent Manager worktree session. [Source](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.20)
- **Hosted workspaces in the local API** (v7.8.21). The local session-host API can now create, list, read and delete hosted workspaces and start sessions in them. [Source](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.21)
- **Bug fixes** (v7.8.20, v7.8.23, v7.8.25). Six fixes cover compaction, background job exit codes, scheduled tasks run by several processes and the npm user-agent; v7.8.22 has no notes of its own. [v7.8.20](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.20), [v7.8.22](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.22), [v7.8.23](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.23), [v7.8.25](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.25)
