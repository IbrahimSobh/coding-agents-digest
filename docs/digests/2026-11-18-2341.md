### Antigravity CLI
- **Plugin validation from a zip or GitHub link** (1.5.11). `agy plugin validate` now accepts a plugin `.zip`, an `https` link to one, or a GitHub repo URL, so you can check a plugin before you install it. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.11)
- **Vim undo works like Vim** (1.5.11). `u` now undoes one command at a time, and an insert such as `cw` or `o` undoes together with the text typed before `Esc`. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.11)
- **Quota commands no longer hang with an API key** (1.5.11). `/usage`, `/quota` and `/credits` now explain why they cannot show a quota when you use `GEMINI_API_KEY`, and in `-p` runs they exit with code 2. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.11)
