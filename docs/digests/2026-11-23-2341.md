Claude Code, Antigravity CLI · 2 releases, 104 bug fixes

### Claude Code
- ⚠️ **Managed plugin marketplaces auto-update by default** (2.1.331). From November 30, 2026, marketplaces listed in managed `extraKnownMarketplaces` update on their own, so set `"autoUpdate": false` on an entry to keep it fixed. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.331)
- **Uncompressed responses on request** (2.1.331). `CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION` asks for uncompressed model responses, for a proxy that cuts off compressed ones. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.331)
- **`claude doctor` checks the API** (2.1.331). A new section reports whether the API can be reached, with the HTTP status or the error. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.331)
- **`PermissionDenied` retry is narrower** (2.1.331). With `retry: true`, Claude now makes a refused call again only when you asked for that call. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.331)

### Antigravity CLI
- ⚠️ **Orchestrator effort now defaults to high** (1.5.15). Planner and Executor effort in the Orchestrator row now defaults to `high` when unset, so set both to the highest level in `/model` to keep the old depth. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.15)
- **Auto-compaction threshold override** (1.5.15). `AGY_CLI_AUTO_COMPACT_OVERRIDE` takes a token count, a `K` or `M` shorthand, or a percentage such as `80%`, and `/context` shows the active value. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.15)
- **Conversations kept by default** (1.5.15). Saved conversations are no longer pruned to the 500 most recent, so `~/.gemini/antigravity-cli/conversations` can grow. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.15)
