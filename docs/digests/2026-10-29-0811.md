### Antigravity CLI
- **Lighter streaming** (1.4.10). Agent replies write about 70% fewer bytes to the terminal, which keeps output smooth over slow SSH connections. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.10)
- **Large images no longer rejected** (1.4.10). Images are capped at 2000 pixels per side and large PNGs are sent as JPEGs, so conversations with many screenshots stop failing on the request size limit. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.10)
- **Less memory after startup** (1.4.10). About 100 MB left over from startup goes back to the operating system 15 seconds after the interactive UI opens; print and headless modes are unaffected. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.10)
