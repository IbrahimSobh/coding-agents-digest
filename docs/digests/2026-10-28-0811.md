### Claude Code
- ⚠️ **Safety event no longer sent** (2.1.312). Claude Code stops sending the `claude_code.safety_event` OpenTelemetry event, so change any alert or dashboard that counts it. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.312)
- ⚠️ **Model switches cover custom model names** (2.1.312). After a flagged message, Claude Code can now switch models for unrecognized names such as custom deployment names; set `CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1` to keep the old behavior. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.312)
- **Click to send in fullscreen** (2.1.312). Clicking the "to send now" hint under a queued message sends it right away, as its key does. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.312)
