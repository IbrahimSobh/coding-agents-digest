### Claude Code
- **Code Mode, opt-in** (2.1.323). Claude can write JavaScript to call its tools; the docs explain how to turn it on, or turn it off for an organization. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.323)
- **Plugin version range** (2.1.323). A plugin declares `engines["claude-code"]` in `plugin.json`, and a plugin outside its stated Claude Code version range is not installed, updated or loaded. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.323)
- **Bash `rm` prompt fix** (2.1.323). A Bash permission check judged an `rm` from the wrong folder, so the dangerous-removal prompt could be skipped under bypass permissions or a Bash allow rule. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.323)

### Antigravity CLI
- ⚠️ **Terminal sandbox proxy path bypass fixed** (1.5.8). Percent-encoded slashes, backslashes or `..` in a URL path could get around path-based network rules, such as those limiting where credentials are sent; update to 1.5.8 or later. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.8)
- ⚠️ **Windows command rules need an exact match** (1.5.8). For `cmd` and PowerShell, always-allow rules now match only the exact command, so write each command as its own rule or expect approval prompts again. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.8)
- **Gemini 4 models** (1.5.8). Gemini 4 Hydrogen and Gemini 4 Carbon appear in `/model` and `--model` when you connect with a `GEMINI_API_KEY`. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.8)
