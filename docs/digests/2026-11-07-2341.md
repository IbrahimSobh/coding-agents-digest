### Antigravity CLI
- ⚠️ **Terminal sandbox security fix** (1.5.3). A command run in the terminal sandbox could change environment state that later persistent terminal commands outside the sandbox loaded, so update to 1.5.3 or later. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.3)
- **Plugin hooks get `PLUGIN_ROOT` and `PLUGIN_DATA`** (1.5.3). Hook commands from a plugin can now read the plugin's bundled files and keep state between runs in its persistent data folder. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.3)
- **Enterprise gateway `/v1beta` 404 fixed** (1.5.3). Model requests no longer all fail with a 404 when the enterprise gateway URL ends in `/v1beta`, because that trailing part is now ignored. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.3)
