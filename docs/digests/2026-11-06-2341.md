### Claude Code
- ⚠️ **Security fixes for Bash permissions, sed and worktrees** (2.1.319). It closes a Bash permission bypass where a crafted environment prefix could hide part of a command, a `sed` check that could be skipped in accept-edits and auto mode, and a sandbox escape when creating a worktree; update to 2.1.319 or later. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)
- ⚠️ **Auto mode can ask or deny without the server check** (2.1.319). With telemetry or feature flags off, including behind LLM gateways, actions the server cannot check are asked about or denied, so `claude -p` runs may stop; set `CLAUDE_CODE_AUTO_MODE_SERVER=0` to keep the built-in classifier. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)
- ⚠️ **`claude -p` exits 1 when auto mode refuses actions** (2.1.319). Text and JSON output used to exit 0 in that case; scripts that trust exit 0 should treat exit 1 as a refused run. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)
- ⚠️ **Self-paced `/loop` stops when a turn ends without rescheduling** (2.1.319). It no longer schedules a fallback wakeup, so a loop can end early; set `CLAUDE_CODE_LOOP_KEEPALIVE=1` to keep the old behavior. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)
- **`permissions.denyInsteadOfPrompting` setting** (2.1.319). A tool call that would wait for a permission prompt is denied and the turn continues, in terminal sessions, subagents and teammates; useful for unattended runs. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)
- **MCP tasks run in the background** (2.1.319). When an MCP server runs a tool call as a task, Claude Code moves it to the background and reports the result when it finishes; set `CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND` to wait inside the call instead. [Source](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)
