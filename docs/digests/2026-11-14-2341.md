### Antigravity CLI
- ⚠️ **HTTP MCP headers stay on their own server** (1.5.9). Custom headers such as API keys are no longer forwarded to another host when the server answers with a redirect, so update to 1.5.9 or later. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.9)
- **`run_workflow` tool** (1.5.9). The agent can run a Python workflow script that fans work out to subagents in parallel or in stages, using the Python bundled with the CLI, so no separate Python install is needed. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.9)
- **Faster Auto mode review** (1.5.9). The reviewer of commands that would leave the terminal sandbox can search the conversation and files directly, so it decides faster and times out less. [Source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.5.9)
